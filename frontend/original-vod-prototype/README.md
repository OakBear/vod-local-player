# 原版课堂实录 · 本地适配实验

这是独立于 `course-player.html` 的实验，不替换已有播放器。它使用学校原版播放中心的 HTML、JavaScript、样式和播放器资源，并通过 `server.py` 将部分原平台接口适配到 head2 的本地后端。

## 启动

先连接 SSH 隧道并确保 `http://127.0.0.1:18080/api/courses` 可访问。在本目录运行：

```powershell
python server.py
```

然后访问 `http://127.0.0.1:18766/`。服务仅监听本机；关闭命令窗口后它会停止。实验页面本身从 18766 加载资源，课程数据和视频经 18080 获取。内容安全策略限制页面访问本机，运行时不从学校拉取资源。

## 已适配

- 原版播放器和双视频、课程切换、节次列表。
- 本地视频、已下载的字幕文本、PPT 节点文字、课堂概要。
- 本地传输速率角标；使用浏览器记录的进度向原版接口提供续播信息。

## 实验限制

- 接口适配不完整；原平台收藏、提问、笔记、下载、反馈、统计上报等在线功能不可依赖。
- PPT 节点截图没有下载到本地，节点时间和识别文字可用，原版缩略图可能为空。
- 本机续播只保存在 18766 的浏览器站点中，与 18765 播放器及其他浏览器不共享；本地记录在清除站点数据后会丢失。
- 当前按课程的首节或本机记录进入；暂未验证所有节次、所有设备，以及异常和断线场景。
- 静态资源来自该平台公开下发的浏览器资源，仅用于本地适配实验。
